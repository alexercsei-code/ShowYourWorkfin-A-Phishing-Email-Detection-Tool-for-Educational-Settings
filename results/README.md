# Results

Figures and tables produced by the notebooks and used in the dissertation. `data/README.md` lists which
notebook makes each file.

Key files:
- `table_leave_one_source_out.csv`, `fig_leave_one_source_out.png` – main cross-source evaluation
- `table_thresholds_cross_source.csv` – basis for the app's 30% / 70% warning bands
- `table_held_out_tests.csv` – synthetic education set and EduPhish (reference only)
- `table_demo_examples_scored.csv` – the 15 demonstration emails with model scores
- `table_feature_weights.csv` – SVM coefficients for every feature
